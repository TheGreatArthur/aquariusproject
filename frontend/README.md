# Aquarius — front end

Next.js 16 (App Router, React 19) application styled with Tailwind CSS (tokens in `tailwind.config.js`, shared
classes in `app/globals.css`); reusable UI lives in `components/`. Design rules: [docs/design-rules.md](../docs/design-rules.md). See the [root README](../README.md) for setup: `make dev` from the repository root.
